# Logos de canales

En esta carpeta se pueden poner los PNG de los canales del panel **Antena TV**.
No se incluyen logos de televisiones en el repositorio para evitar distribuir
marcas de terceros.

Si no hay imágenes, el panel funciona igual: muestra una insignia con el número
de canal. Para añadir un logo, usa el nombre que espera `app.js`, por ejemplo:

```text
la1.png
la2.png
antena3.png
cuatro.png
telecinco.png
lasexta.png
fdf.png
telemadrid.png
```

Usa solo imágenes que tengas derecho a utilizar. Los logotipos son marcas de
sus propietarios.
